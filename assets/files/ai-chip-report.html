2. 技術架構示意圖

┌─────────────────────────────────────────────────────────┐
│ AI 加速晶片系統架構 │
├─────────────────────────────────────────────────────────┤
│ 應用層 → LLM 訓練 / 推論 · 電腦視覺 · 科學計算 · 邊緣 AI │
│ 框架層 → PyTorch / TensorFlow · CUDA / ROCm · ONNX │
│ 硬體抽象層 → NVIDIA CUDA · AMD ROCm · Intel oneAPI │
│ 晶片核心 → GPU / NPU / TPU → Tensor Core │
│ 記憶體與互連 → HBM3 / HBM3e → NVLink / Infinity │
│ 製造與封裝 → 台積電 N3E / N2 · CoWoS-L / SoIC │
└─────────────────────────────────────────────────────────┘

核心技術要點

  1. HBM（高頻寬記憶體）：主流 HBM3（每顆 12 層，頻寬 >900 GB/s）；HBM3e 已量產，HBM4 試產（目標 1.5 TB/s+）。
  2. 3D 封裝（CoWoS-L）：晶片與記憶體垂直堆疊，縮小訊號距離、降低延遲。台積電 CoWoS 產能為全球 AI 晶片供應關鍵瓶頸。
  3. 製程節點：NVIDIA Blackwell → 台積電 N4P；AMD MI350 → N3E；Intel Gaudi 3 → N5（TSMC 製造）。
  4. 能源效率競爭：從「純算力競賽」轉向「每瓦效能（Performance per Watt）」，這對資料中心 OPEX 至關重要。

3. 產業鏈關聯性

上游（材料 / 設備）中游（晶片設計 / 代工）下游（系統 / 應用）
矽晶圓（環球晶圓）、光刻機（ASML）、化學材料（信越、JSR）NVIDIA、AMD、Intel（設計）→ 台積電、三星（代工）雲端（AWS / Azure / GCP）、AI 伺服器（Supermicro、Dell、HPE）、邊緣裝置（車用、工業 PC）

台新藥在此產業鏈中的角色：非直接參與晶片製造，而是透過 ADC（抗體藥物複合體）生物相似藥與 APNT 奈米微粒製劑技術，在生技領域與晶片產業形成「生技 + AI 計算」的交集應用（例如：AI 輔助藥物發現、臨床試驗數據分析、個人化醫療模型訓練）。

4. 競爭態勢與風險

競爭格局（2026 年觀察）

  • NVIDIA 壟斷訓練市場：Blackwell 系列在 LLM 訓練仍無對手，CUDA 生態鎖定效應極強。
  • AMD 逐步搶占推論市場：MI350 在推論成本效益（Cost per Inference）上對 NVIDIA 形成壓力，尤其在企業內部部署場景。
  • Intel 以低功耗切入邊緣：Gaudi 3 主打「高性價比 + 低功耗」，適合不需要極致算力的推論任務（醫療影像分析、工業檢測）。
  • 台積電為最大贏家：無論晶片設計廠商競爭結果如何，幾乎所有高階 AI 晶片都由台積電代工（N3E / N2 製程 + CoWoS 先進封裝）。

主要風險

  1. 製程與封裝產能限制：CoWoS 產能緊張可能導致晶片出貨延遲（已影響 NVIDIA Blackwell 初期交貨）。
  2. 地緣政治風險：美國對中國的晶片出口管制（包括高階 GPU 與製造設備）可能影響全球供應鏈與市場需求。
  3. 能源與散熱成本：每顆晶片功耗持續上升（Blackwell B200 單卡 TDP 達 1000W 以上），資料中心電力與散熱成為營運關鍵限制。
  4. 技術替代風險：光子晶片（Photonic Chip）或類腦晶片（Neuromorphic Chip）若在 2028~2030 年實現商業化，現有電子晶片架構可能面臨顛覆。

5. 總結與觀察重點

  • AI 晶片不是單一產品競爭，而是「設計 + 製造 + 軟體生態 + 能源管理」的系統競爭。
  • 短期（2026~2027）：NVIDIA 仍主導，AMD 與 Intel 在特定細分市場（推論、邊緣、企業內部）逐步擴張。
  • 中期（2028~2030）：HBM4、3nm 以下製程（N2）、光子互連（CPO）將成為下一輪技術分水嶺。
  • 對台新藥的意義：雖然公司核心業務為生技藥物（ADC、眼科新藥），但 AI 計算能力的提升（藥物發現、臨床數據分析、個人化治療模型）將間接加速公司研發效率，並降低臨床試驗成本。
