寫文章後台

這個站不用記檔名格式，用下面兩個免費視覺編輯器就行，都是用你的 GitHub 帳號登入。

方法 A：prose.io（最像 WordPress，推薦）

手機、電腦都能用，打字、上傳圖片、存檔就發佈。

用 prose.io 寫新文章 用 prose.io 管全部檔案

第一次會問你要授權 prose.io 存取 GitHub，按 Authorize 就好。新增檔案時檔名照 2026-09-12-標題.md，開頭貼一次下面這段，之後都用打字的：

---
layout: post
title: "這裡寫標題"
date: 2026-09-12 09:00:00 +0800
categories: 生活
---

內文從這裡開始

方法 B：github.dev（VS Code 網頁版，有預覽）

按 . 鍵的雲端版，適合想左右對照看效果的人。

用 github.dev 開啟倉庫

開啟後在左邊進 _posts 新增檔案，右上角有預覽可以看排版。

發佈後去哪看？

回首頁 ・ 看部署進度 Actions

存檔後等 1-2 分鐘網站會自動更新。如果沒看到，去 Actions 看是不是還在跑（黃點就是還在部署）。
