寫文章後台

這個站不用記檔名格式，用下面兩個免費視覺編輯器就行，都是用你的 GitHub 帳號登入。

方法 A：GitHub 網頁（最穩，推薦）

直接在倉庫裡新增、編輯檔案，存檔就發佈，不會壞。

去 _posts 寫新文章 開啟倉庫首頁

按 Add file > Create new file，檔名照 2026-09-12-標題.md（英文、不要空格、結尾 .md），第一行一定要是 ---。

---
layout: post
title: "這裡寫標題"
date: 2026-09-12 09:00:00 +0800
categories: 生活
---

內文從這裡開始

方法 B：github.dev（VS Code 網頁版，有預覽）

按 . 鍵的雲端版，適合想左右對照看效果的人。

用 github.dev 開啟倉庫

開啟後在左邊進 _posts 新增檔案，右上角有預覽可以看排版。

方法 C：prose.io（目前不穩，先不要用）

2026 年有人回報提交會失敗，你之前遇到的 從 Github 加載信息時出現了錯誤 就是它壞掉，不是你按錯。等它修好再說。

發佈後去哪看？

回首頁 ・ 看部署進度 Actions

存檔後等 1-2 分鐘網站會自動更新。如果沒看到，去 Actions 看是不是還在跑（黃點就是還在部署）。
